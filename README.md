🎣 GoFishGame

GoFishGame is a Java-based implementation of the classic card game Go Fish — designed as a programming exercise or playable console project that models turn-based logic and basic game rules.

Players (human or AI) take turns asking each other for card values in an effort to collect matching sets (“books”). The game continues until all possible sets are completed or the deck is exhausted. Gameplay mechanics include dealing hands, requesting cards, handling “Go Fish!” draws, and tracking collections.

This project emphasizes:

Core game logic built in Java

Simple simulation of Go Fish rules

Object-oriented structure ideal for learning or extension

Foundational structure for adding UI or AI behavior

Whether you’re exploring Java, building card game logic, or expanding it with graphics or smarter opponents, this repo offers a solid starting point for a classic card game experience.
